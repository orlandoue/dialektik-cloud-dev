# Dialektik Flutter application

This directory contains the production Flutter foundation. Phase 0 implements
application bootstrap, design tokens, function-bound themes, foundational
widgets, accessibility helpers, asset metadata, and executable design-safety
checks. It intentionally contains no product feature or domain model.

See the repository-level `README.md` for bootstrap, quality, specification
authority, and blocker information. Start Flutter work from `app/AGENTS.md` and
use `docs/SPEC_INDEX.md` to load only the relevant API/UX/design/accessibility
sources.
