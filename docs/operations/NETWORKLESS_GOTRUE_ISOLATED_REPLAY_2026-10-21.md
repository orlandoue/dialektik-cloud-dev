Networkless GoTrue v2.197.0 test runs with a local, synthetic Supabase PG17 database. First pulls all images, then stops ancillary services and removes *all* external DB networks before loading the Auth service under Docker --network container:<db>. Node.js exercises signup, password login, JWT identity and invalid-login rejection through loopback port 9999. No host port, public network, real user password, existing restored Auth data, external Supabase instance or Render secret is involved. On success this establishes that the same design can be considered for a strictly protected offline real-backup smoke, but that separate job must keep authentic data inside the no-egress ephemeral runner and verify cleanup. This is not a test of the original account's password or session tokens and is not permission to enable writer LOGIN or apply 043/044.
